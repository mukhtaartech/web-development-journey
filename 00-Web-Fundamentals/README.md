# 🌐 Web Fundamentals

Welcome to the foundation of my web development journey.

Before learning how to build websites, I want to understand **how the web actually works**.

This section contains my notes and practical understanding of the technologies and concepts that make websites and web applications possible.

---

## 🎯 Objective

The goal of this section is to understand what happens behind the scenes when a user opens a website.

For example:

```text
User
  ↓
Web Browser
  ↓
DNS
  ↓
Web Server
  ↓
HTTP/HTTPS Request
  ↓
Server Processing
  ↓
HTML / CSS / JavaScript
  ↓
Browser
  ↓
Web Page
```
